Getting Started

NexaKS is a script authentication system with HWID locking, license keys, and per-project script serving. Here's the quick flow for new users:

  1. Get a license key from an admin or purchase channel.
  2. Redeem the key - either on this website via Dashboard -> Redeem Key, or on Discord using /redeem.
  3. Copy your loader script from the Dashboard or the Discord panel.
  4. Paste the loader into your Roblox executor and run.
First execution binds your key to your device (HWID). If you switch devices, use Reset HWID (24-hour cooldown).

Discord Bot Commands

The Discord bot is where most users manage their license day-to-day. Below is every available command.

For All Users

/redeem key:NXKS-...Activate a license key on your Discord account.
/keyinfoView your license details - plan, expiry, HWID, executions.
/resethwidUnlink your device so you can bind a new one. 24h cooldown, 5 resets max.

Panel Buttons

Admins post an interactive panel with these buttons - no typing needed. Panels can be tied to a specific project (e.g. /setup-panel project:autoparry) so Get Script serves the right loader for that channel:

  • Redeem Key - opens a form to paste your key
  • Get Role - assigns the Verified role once you have an active key
  • Get Script - sends your loader via DM (or ephemeral reply if DMs are closed)
  • Reset HWID (24h) - shows confirmation, then resets your hardware ID
  • Session Status - same as /keyinfo
  • Open Dashboard - link to this website
DM tip: Enable "Allow direct messages from server members" in your Discord privacy settings so the bot can DM your loader privately.

Using the Dashboard

The Dashboard is your control center for a single license. Sign in with Discord to access it.

What each card shows

  • License Status - active, expired, or revoked
  • Expires In - days left before your license needs renewal
  • HWID Resets - how many device changes you've used out of 5
  • Executions - how many times the script has run on your key

Actions

  • Redeem Key - paste a new key to activate
  • Copy (on License Key card) - copies your key to clipboard
  • Reset HWID - unlinks your device (24h cooldown)
  • Copy Loader - copies the ready-to-paste loader for your executor

Activity log

The Activity section shows the last 10 events on your account - redeems, HWID resets, script executions, and failed attempts. Use it to check if your key is being used from unexpected devices.

Projects (For Owners)

Projects are containers for your scripts. If you own scripts and want to sell/share them, this is where you organize them.

Creating a project

  1. Go to Projects -> New Project.
  2. Enter a name (e.g. "Blox Fruits Hub") and a slug (short URL id like bloxfruits).
  3. Click Create - you'll be taken to the project detail page.

What's inside a project

  • Scripts - the Lua code that gets served. Each script has a plan (Free/Pro/Enterprise), a Keyless toggle, and a Publish/Draft status. Only published scripts go live.
  • Blacklist - ban specific HWIDs, IPs, or users from this project.
  • Whitelist - pre-approve specific HWIDs or users (only enforced if whitelist-only mode is on).
  • Activity - the last 20 events specific to this project.

Getting the loader

Once a script is published, click the Loader button beside it. A modal will show the exact loadstring code to distribute:

  • Keyless script -> 1-line loader, runs for anyone
  • Key-based script -> 2-line loader with _G.script_key placeholder to fill in
Keys must be attached to a project. When you generate a key, link it to the right project so users get the correct script. Ask your admin to help if you're unsure.

Using the Loader in Roblox

The loader is a short piece of Lua code that verifies your key and runs the protected script. Two formats:

Keyless (open access)

loadstring(game:HttpGet("https://keyora-gyuu.onrender.com/api/load/PROJECT?script=SCRIPT_ID"))()

Just paste and run - no key needed.

Key-based (license required)

_G.script_key = "NXKS-XXXX-XXXX-XXXX-XXXX"
loadstring(game:HttpGet("https://keyora-gyuu.onrender.com/api/load/PROJECT?script=SCRIPT_ID&key=".._G.script_key))()

Replace NXKS-XXXX-... with your actual key from the Dashboard, then paste and run.

How to run it

  1. Open your Roblox executor (Delta, Wave, Solara, etc.)
  2. Copy the entire loader - every character matters
  3. Paste into the executor's script box
  4. Click Execute / Run
Never share your key-based loader. It contains your personal license. Sharing = permanent revocation and ban.

Plans - Free, Pro, Enterprise

Every key and script has a plan tier. This lets you offer different features to different customers.

FreeTrial / basic tier - usually keyless or limited features.
ProStandard paid tier - full features.
EnterprisePremium tier - everything + priority.

How matching works

When a user loads a script, the system picks the script whose plan matches the user's key plan. If there's no exact match, it falls back to the Free script - so always publish a Free version if you want everyone to have something.

If you only have one tier, just use Free for both key and script - the tier system is optional.

Admin Setup (For Owners)

Making yourself an admin

Run this in Supabase -> SQL Editor (replace with your Discord user ID):

UPDATE users SET is_admin = true
WHERE discord_id = 'YOUR_DISCORD_USER_ID';

Get your Discord ID: enable Developer Mode (Settings -> Advanced), then right-click your username -> Copy User ID.

Admin Discord commands

/setup-panel project:SLUGPost the interactive panel, optionally tied to a project.
/generate plan:pro duration:30 quantity:5 project:SLUGGenerate license keys. Add project:SLUG to tie keys to a specific project (recommended). Durations: 1, 7, 30, 90, 365, or lifetime.
/revoke key:NXKS-...Revoke a key - user loses access immediately.
/lookup user:@nameLook up a user's account, keys, and status.

Attaching keys to a project

The easiest way: pass project:SLUG when generating keys, and they'll be auto-linked:

/generate plan:pro duration:30 quantity:5 project:autoparry

To re-link an existing key (or one generated before this feature), run in Supabase:

UPDATE keys
SET project_id = (SELECT id FROM projects WHERE slug = 'YOUR_SLUG')
WHERE key = 'NXKS-XXXX-XXXX-XXXX-XXXX';
Multi-project channels: post one panel per project channel using /setup-panel project:SLUG. When a user clicks Get Script, they only get the loader for that panel's project - and only if they own a key attached to it.

Troubleshooting

"Invalid license key"

The key doesn't exist or hasn't been generated. Double-check spelling (keys are case-sensitive) and make sure you got it from a legitimate source.

"Hardware ID mismatch"

You're running on a different device than the one your key is bound to. Use /resethwid on Discord (24h cooldown) or the Reset HWID button on the Dashboard.

"License expired"

Your key's duration has ended. Contact the admin for renewal or purchase a new key.

"This project is currently paused"

The project owner paused the project. Nothing you can do until they resume it - reach out to the owner.

"Access denied - blacklisted"

Your HWID, IP, or account has been blacklisted from this project. Contact the owner if you think this is a mistake.

"Script not found or not published"

The project has no published script for your plan. Either the owner hasn't uploaded one yet, or they only published a higher-tier script than your key.

Empty response / network error

The server might be waking up (first request after inactivity can be slow). Wait 30 seconds and try again. If it persists, contact the admin.

Loader doesn't do anything

  • Make sure you copied the entire loader - every character.
  • Make sure your executor supports HttpGet and loadstring (most modern ones do).
  • Check the executor console for any warning messages starting with [NexaKS].
Still stuck? Ask on Discord - provide the exact error message and what you were doing when it happened.
