Discord Bot Commands
Complete list of slash commands and panel buttons
/redeem key: NXKS-XXXX-XXXX-XXXX-XXXX
Redeem a license key. Auto-assigns Verified role plus your project role (Macro / Private / Premium) based on what you purchased.
User
/resethwid
Reset your hardware ID so you can use the script on another device. 15-hour cooldown between resets, 5 max per key.
User
/keyinfo
View your active license details - plan, expiry, HWID binding status, and remaining resets.
User
/setup-panel [project: slug]
Post the interactive button panel in the current channel. Add project to tie the panel to one specific script.
Admin
/generate plan - duration - [quantity] - [project]
Generate new license keys. plan: free / pro / enterprise - duration: 1 / 7 / 30 / 90 / 365 / lifetime days - quantity: 1-50.
Admin
/revoke key: NXKS-XXXX-...
Revoke a license key. The user loses access immediately.
Admin
/lookup user: @someone
Look up a user profile - total keys, active count, revoked count, admin status, ban status.
Admin
/setrole user: @someone - project: Macro | Private | Premium
Manually assign a project role. Useful when the auto-assign on redeem fails or for special cases.
Admin
/forcereset user: @someone
Owner only. Force-reset a user's HWID. Bypasses the 15-hour cooldown AND restores the reset counter to 0/5.
